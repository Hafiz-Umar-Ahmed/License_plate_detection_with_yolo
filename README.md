# License Plate Detection with a Fine-Tuned YOLOv8n

Deep Learning project, BSE-7A.
Team: Hafiz Umar (23K-0035), Naveed Ahmed (23K-3025), Imam Ali Mehdi (23K-3029)

Single-class object detection (`license_plate`): a COCO-pretrained **YOLOv8n** is fine-tuned on the
[`keremberke/license-plate-object-detection`](https://huggingface.co/datasets/keremberke/license-plate-object-detection)
dataset. An optional EasyOCR step reads the detected plates (out of project scope).

## Results (held-out test split, 885 images / 905 plates)

| Precision | Recall | mAP@0.5 | mAP@0.5:0.95 | Inference |
|---|---|---|---|---|
| 0.990 | 0.973 | 0.991 | 0.716 | 2.7 ms/img (Tesla T4) |

Validation, epoch 1 (baseline A) vs epoch 50: mAP@0.5 0.934 -> 0.989, mAP@0.5:0.95 0.602 -> 0.708.
Training: 50 epochs, about 72 min on a T4. Full discussion is in the report.

## Dataset

* Source: Hugging Face Hub, `keremberke/license-plate-object-detection` (Roboflow export), config `default`,
  revision `refs/convert/parquet`. Downloaded automatically by the notebook; nothing to download by hand.
* Size: 6,179 train / 1,768 validation / 885 test images, one class. Official splits are kept unchanged.
* Annotations: COCO boxes `[x, y, w, h]`, converted by the notebook to YOLO labels (section 3).
* Check the dataset card for the licence and cite it in anything you redistribute.

## How to run

### Option A: Google Colab (recommended)
1. Upload `License_Plate_Detector.ipynb` to Colab; set *Runtime > Change runtime type > T4 GPU*.
2. Create a folder `results/` in the Colab file browser and upload `results.csv` into it (needed for the baseline table and curves).
3. In section 0, choose a mode:
   * **Quick run (no training):** keep `RUN_TRAINING = False` and upload your trained `best.pt` to the path in `WEIGHTS_PATH`
     (default: `/content/runs_license_plate/yolov8n_finetuned/weights/best.pt`). To keep weights across sessions
     set `USE_GOOGLE_DRIVE = True`, which stores them under `MyDrive/license_plate_detection/`.
   * **Full reproduction:** set `RUN_TRAINING = True` (about 72 minutes).
4. *Runtime > Run all*.

### Option B: local machine
```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab License_Plate_Detector.ipynb
```
A CUDA GPU is strongly recommended; on CPU training is impractically slow, but evaluation and inference work.
The notebook writes datasets and runs under the current working directory.

## Run switches (notebook section 0)

| Flag | Default | Effect |
|---|---|---|
| `RUN_TRAINING` | `False` | Fine-tune YOLOv8n (about 72 min on T4) instead of loading `best.pt` |
| `RUN_BASELINE_SCRATCH` | `False` | Also train from random initialisation (Baseline B), slow |
| `RUN_OCR_DEMO` | `True` | EasyOCR extension on 10 random test images |
| `USE_GOOGLE_DRIVE` | `False` | Colab only: persist outputs on Drive |

## Reproducibility notes

* Seed 0, `deterministic=True`. Reported environment: Ultralytics 8.4.x, PyTorch 2.x, Python 3.13, Tesla T4.
* Expect small differences (typically < 0.5 mAP points) across GPUs and library versions.
* Hyper-parameters: epochs 50, imgsz 640, batch 16, AdamW (auto), AMP, patience 10 (never triggered), Ultralytics default augmentation.

## Known issues

* Three validation records are lost on conversion because of repeated `image_id`/filename pairs (1,768 loaded vs 1,765 files); the test split is unaffected.
* No ground-truth plate text exists, so OCR is only assessed qualitatively.
* Baseline B (from scratch) and the error-gallery images must be generated by running the notebook.
